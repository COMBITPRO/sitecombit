# Комбит Про — лендинг

Статический сайт на Astro. Для локальной разработки:

```sh
npm install
npm run astro -- dev --background
```

Production-сборка создаётся командой `npm run build` в каталоге `dist`.

## Управление контентом

Тексты, контактные данные, карточки и изображения вынесены в `src/content/site.json`. Заказчик может редактировать их через бесплатный [Pages CMS](https://pagescms.org/), не работая с исходным кодом:

1. Разместите репозиторий на GitHub и откройте [Pages CMS](https://app.pagescms.org/).
2. Авторизуйтесь через GitHub и предоставьте сервису доступ к этому репозиторию.
3. Выберите раздел «Содержимое сайта», внесите изменения и нажмите Save.
4. Pages CMS создаст коммит в репозитории. Если Layero подключён к этому репозиторию с автоматическим деплоем, сайт пересоберётся после коммита.

Конфигурация редактора находится в `.pages.yml`. В ней доступны только контентные поля; дизайн, стили и компоненты через CMS не редактируются. Изображения, загруженные заказчиком, сохраняются в `public/images`.

Перед передачей доступа рекомендуется создать для заказчика отдельную учётную запись GitHub и выдать ей доступ только к этому репозиторию.

## Форма обратной связи

Заявки отправляются из собственной формы сайта в Formspree через AJAX. Пользователь остаётся на лендинге, а Formspree пересылает данные на подтверждённые адреса электронной почты.

Для подключения и локального тестирования:

1. Зарегистрируйтесь на [Formspree](https://formspree.io/) и создайте новую форму.
2. Добавьте и подтвердите адреса получателей уведомлений.
3. Скопируйте endpoint вида `https://formspree.io/f/xxxxxxxx`.
4. Создайте локальный `.env` на основе `.env.example` и укажите endpoint в `PUBLIC_FORMSPREE_ENDPOINT`.
5. Перезапустите dev-сервер и отправьте тестовую заявку.

Если endpoint не задан, кнопка отправки отключена. Секретов в этой переменной нет: Formspree специально выдаёт публичный адрес для клиентских форм.

## Деплой на Layero

Проект остаётся статическим и не зависит от конкретного хостинга. В Layero добавьте `PUBLIC_FORMSPREE_ENDPOINT` как переменную окружения сборки и выполните новый деплой. На бесплатном тарифе сайт будет доступен на поддомене `*.layero.ru`; собственный домен требует платного тарифа Layero.
