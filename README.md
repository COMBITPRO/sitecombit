# Комбит Про — лендинг

Статический сайт на Astro. Для локальной разработки:

```sh
npm install
npm run dev
```

Production-сборка создаётся командой `npm run build` в каталоге `dist`.

## Форма обратной связи

Без дополнительной настройки форма подготавливает письмо на `info@kombit.ru` в почтовой программе посетителя.

Для полноценного сбора заявок без собственного бэкенда:

1. Создайте и опубликуйте форму в [Яндекс Формах](https://forms.yandex.ru/).
2. Скопируйте URL формы из кода для встраивания.
3. Добавьте в Cloudflare Pages переменную окружения `PUBLIC_YANDEX_FORM_URL` со значением URL.
4. Запустите новый deployment. Встроенная Яндекс Форма автоматически заменит локальную форму-заглушку.

Локально значение можно указать в файле `.env`, используя `.env.example` как образец.
